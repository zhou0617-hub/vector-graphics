# 技术栈与环境

## 一、项目定位

图片转 SVG 工具 + 社区分享平台。

**已完成**
- 用户系统：注册、登录、JWT 鉴权
- 转换链路：图片上传 → 矢量化 → 保存 SVG
- 文件管理：我的文件列表、下载
- 前端基础页面：首页、登录、注册、转换工作台、我的文件

**待开发**
- 社区模块

## 五、从零复现步骤

```bash
# 1. 环境准备
brew install node openjdk@21 maven python@3.11
# 安装 Docker Desktop
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 21)' >> ~/.zshrc
source ~/.zshrc

# 2. 启动中间件
cd ~/Desktop/Vector_Graphics
docker compose up -d
docker compose ps

# 3. Python 矢量化
cd vectorizer
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
deactivate
cd ..

# 4. 后端编译
cd backend && ./mvnw clean compile && cd ..

# 5. 前端依赖
cd frontend && npm install && cd ..

# 6. 启动所有服务
node scripts/start-dev.js

# 7. 验证
curl http://localhost:8000/api/health
curl http://localhost:8080/api/health
open http://localhost:3000
```

### 七、新增 esrgan-service 虚拟环境初始化

```bash
cd esrgan-service
python3 -m venv .venv
source .venv/bin/activate

# 1. PyTorch CPU 版（macOS）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 2. tb-nightly（阿里云源）
pip install tb-nightly -i https://mirrors.aliyun.com/pypi/simple

# 3. Web 框架
pip install fastapi "uvicorn[standard]" python-multipart pydantic-settings pillow numpy opencv-python-headless -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. basicsr-fixed + realesrgan
pip install basicsr-fixed realesrgan -i https://pypi.tuna.tsinghua.edu.cn/simple

# 5. 手动修复 basicsr 兼容问题
sed -i '' 's|torchvision.transforms.functional_tensor|torchvision.transforms.functional|g' \
  .venv/lib/python3.11/site-packages/basicsr/data/degradations.py

deactivate
```

**Windows 用户注意**：

- PyTorch 装 CUDA 版：`pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128`
- `sed` 换成 PowerShell 命令（见 `docs/05-问题排查.md`）

### 九、GPU 支持

RTX 50 系（Blackwell 架构）需要 **CUDA 12.8+**。

```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

旧版 `cu121` 会报 `no kernel image is available for execution on the device`。
