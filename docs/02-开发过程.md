### 业务逻辑

`ConversionService.convert` 流程：

1. 校验文件格式和大小
2. 保存原图到本地
3. 创建 files 记录
4. 创建 conversions 记录（status=processing）
5. 调用 Python 矢量化
6. 保存 SVG
7. 更新 files 记录（svg_url、width、height）
8. 更新 conversions 记录（status=success）
9. 返回结果

失败时更新 conversions 为 failed 并记录错误消息。

### 登录态持久化修复

**问题**：刷新浏览器就要求重新登录。

**原因**

1. RequireAuth 的 useEffect 比 Providers 的 hydrate 先跑
2. user 未持久化，每次刷新都调 `/api/users/me` 补全

**解决**

| 文件 | 改动 |
|---|---|
| `stores/auth-store.ts` | token 和 user 都持久化到 localStorage |
| `stores/auth-store.ts` | 新增 `hydrate()` 恢复状态 |
| `components/require-auth.tsx` | 等 `hydrated=true` 后判断 |
| `components/providers.tsx` | 挂载时调用 `hydrate()` |
| `lib/api/client.ts` | 401 全局拦截，自动清 localStorage 并跳登录 |

**效果**

| 操作 | 是否跳登录 |
|---|---|
| 刷新页面 | 不跳 |
| 重启前端 | 不跳 |
| 重启后端 | 不跳 |
| 重启 Mac | 不跳 |
| token 过期（7 天） | 跳 |
| 手动退出 | 跳 |
| 后端换 JWT 密钥 | 跳 |
| 清空浏览器数据 | 跳 |

### 跨域下载修复

**问题**：`<a href download>` 在跨域时 `download` 属性被浏览器忽略，直接打开 SVG。

**解决**：`lib/utils.ts` 新增 `downloadFile()`

```typescript
export async function downloadFile(url: string, filename: string) {
  const res = await fetch(url, { credentials: 'omit' });
  if (!res.ok) throw new Error(`下载失败 (${res.status})`);
  const blob = await res.blob();
  const blobUrl = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = blobUrl;
  a.download = filename;
  document.body.appendChild(a);
  a.click();
  document.body.removeChild(a);
  setTimeout(() => URL.revokeObjectURL(blobUrl), 1000);
}
```

**原理**

1. `fetch` 请求后端，后端 CORS 允许就返回文件内容
2. `URL.createObjectURL(blob)` 生成当前域的 blob URL
3. 对这个 URL 用 `a.download` 是同域操作，浏览器不限制
4. 部署到任何域名都能工作

### JPG 转换失败修复

**问题**：大 JPG 转 SVG 失败，报"矢量化服务不可用"。

**真实错误**

```
com.fasterxml.jackson.core.exc.StreamConstraintsException: 
String value length (20051112) exceeds the maximum allowed 
(20000000, from StreamReadConstraints.getMaxStringLength())
```

**原因**：SVG 字符串 2000 万字符，超过 Jackson 默认字符串长度限制。

**解决**

| 限制 | 位置 | 默认 | 改成 |
|---|---|---|---|
| WebClient 缓冲 | ExchangeStrategies.maxInMemorySize | 256KB | 200MB |
| Jackson 字符串 | StreamReadConstraints.maxStringLength | 20MB | 200MB |

**代码（VectorizerClient.java）**

```java
this.objectMapper = new ObjectMapper(
    JsonFactory.builder()
        .streamReadConstraints(
            StreamReadConstraints.builder()
                .maxStringLength(MAX_STRING_LENGTH)
                .build()
        )
        .build()
);
```

**同步配置（application.yml）**

```yaml
spring:
  codec:
    max-in-memory-size: 200MB
```

### 最终方案（v6）

**三个交互**

| 交互 | 参数 | 效果 |
|---|---|---|
| 鼠标排斥 | 范围 150px，力 7.0，平方衰减 | 鼠标扫过粒子群，大片粒子让开 |
| 点击涟漪 | 半径 420px，波带宽 70px，力 38 | 点击处出现一圈"空气波"，粒子被径向推开 |
| 粒子互斥 | 范围 16px，力 0.9 | 粒子不堆叠，有自然"呼吸感" |

**关键实现**

- **空间哈希网格**：画布切成 20x20 网格，每粒子只查 3x3 邻域，避免 O(n²) 卡顿
- **波动扩散**：涟漪从 0 扩散到 420px，持续 1200ms，衰减 = 1 - t
- **无金色圆环**：删掉 `ctx.arc` 绘制，只保留粒子被推开的物理效果
