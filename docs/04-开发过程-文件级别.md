# 开发过程（按文件创建顺序）

本文档按文件创建顺序记录整个项目，用于理解每个文件的作用和它们之间的关系。

## 一、目录骨架

### 1. 根目录

```
~/Desktop/Vector_Graphics/
```

### 2. 创建三个子项目目录

```bash
mkdir -p frontend backend vectorizer docs scripts
```

| 目录 | 作用 |
|---|---|
| `frontend/` | Next.js 前端 |
| `backend/` | Spring Boot 后端 |
| `vectorizer/` | Python 矢量化服务 |
| `docs/` | 项目文档 |
| `scripts/` | 跨平台启动脚本 |

### 3. 前端路由分组目录

在 `frontend/src/app/` 下创建：

| 目录 | 作用 |
|---|---|
| `(marketing)/` | 营销页面分组（首页） |

| `(main)/my/favorites/` | 我的收藏（预留） |

## 二、根目录配置文件

### 1. `package.json`

**位置**：`package.json`

**作用**：根级 npm scripts，统一调度三个子项目。

关键脚本：
- `dev` → 调用 `scripts/start-dev.js`
- `init:db` → 调用 `scripts/init-db.js`
- `build` → 调用 `scripts/build.js`
- `frontend` / `backend` / `vectorizer` → 单独启动某个服务

### 2. `.gitattributes`

**作用**：强制换行符统一为 LF，避免 macOS/Linux 与 Windows 冲突。

关键规则：所有文本文件 `eol=lf`，二进制文件（png/jpg）标记为 `binary`。

### 3. `.gitignore`

**作用**：忽略不需要提交的文件。

关键忽略项：`node_modules/`、`.venv/`、`target/`、`.next/`、`data/`、`.env`、`.DS_Store`。

### 4. `.editorconfig`

**作用**：统一编辑器行为。

关键设置：UTF-8、LF、2 空格缩进（Java 用 4 空格）。

### 5. `.nvmrc`

**作用**：锁定 Node.js 版本 20.11.0。

### 6. `docker-compose.yml`

**作用**：定义本地中间件服务。

| 服务 | 镜像 | 端口 |
|---|---|---|
| mysql | mysql:8.0 | 3306 |
| redis | redis:7-alpine | 6379 |
| rabbitmq | rabbitmq:3-management-alpine | 5672 / 15672 |

MySQL 自动建库 `vector_graphics`，自动创建用户 `vg / vg123456`。

### 7. `README.md`

**作用**：项目说明文档，快速入门。

## 三、跨平台脚本

### 1. `scripts/start-dev.js`

**作用**：一键启动三个服务，日志带彩色前缀。

关键逻辑：
- 用 `spawn` 启动三个子进程
- 自动检测平台
- Python 服务直接用 venv 里的 python（不依赖 `source`）
- `Ctrl+C` 时优雅关闭所有子进程

### 2. `scripts/init-db.js`

**作用**：启动 Docker + 等待就绪 + 执行 Flyway 迁移。

### 3. `scripts/build.js`

**作用**：依次构建后端（Maven）和前端（Next.js）。

### 4. `scripts/md2docx.sh`

**作用**：把 `docs/` 下的 `.md` 文件批量转为 `.docx`，方便用 Word 查看。

依赖 pandoc：`brew install pandoc`。

## 四、Python 矢量化服务

### 1. `vectorizer/requirements.txt`

**作用**：Python 依赖清单。

| 包 | 版本 | 用途 |
|---|---|---|
| fastapi | 0.115.5 | Web 框架 |
| uvicorn[standard] | 0.32.1 | ASGI 服务器 |
| python-multipart | 0.0.19 | 处理 multipart/form-data |
| pydantic | 2.10.3 | 数据校验 |
| pydantic-settings | 2.6.1 | 从环境变量读配置 |
| pillow | 11.0.0 | 图片处理 |
| vtracer | 0.6.11 | 矢量化引擎 |

### 2. `vectorizer/app/__init__.py` 等 6 个空文件

**作用**：标记目录为 Python 包。

包括：`app/`、`app/core/`、`app/api/`、`app/services/`、`app/services/engines/`、`app/utils/`。

### 3. `vectorizer/app/core/config.py`

**作用**：服务配置。

关键字段：
- 服务名、debug 开关
- 上传大小限制（10MB）
- 允许格式（PNG / JPG / JPEG / WEBP）
- 临时目录和输出目录
- VTracer 默认参数

用 `pydantic-settings` 从 `.env` 读取。

### 4. `vectorizer/app/api/schemas.py`

**作用**：请求/响应模型。

| 模型 | 作用 |
|---|---|
| `VectorizeParams` | 矢量化参数（11 个可调项） |
| `VectorizeResponse` | 转换结果（svg、宽、高、耗时） |
| `HealthResponse` | 健康检查响应 |

### 5. `vectorizer/app/services/engines/base.py`

**作用**：矢量化引擎抽象接口。

- `VectorizeOptions`：通用参数 dataclass
- `VectorizerEngine`：抽象基类，定义 `name` 属性和 `vectorize` 方法

**设计意义**：为后续接入其他矢量化引擎预留扩展点，业务代码不依赖具体引擎。

### 6. `vectorizer/app/services/engines/vtracer_engine.py`

**作用**：VTracer 引擎实现。

流程：Pillow 打开图片 → 转 RGBA → 转 PNG 字节 → 传给 vtracer → 返回 SVG 字符串。

### 7. `vectorizer/app/services/vectorizer.py`

**作用**：服务层统一入口。

- 持有引擎实例
- 提供 `vectorize()` 方法，返回 `(svg, 耗时毫秒)`

### 8. `vectorizer/app/api/routes.py`

**作用**：HTTP 路由。

| 端点 | 作用 |
|---|---|
| GET `/health` | 健康检查 |
| POST `/vectorize` | 接收图片，校验格式和大小，调用服务，返回 SVG |
| POST `/vectorize/download` | 同上，但响应头带下载文件名 |

### 9. `vectorizer/app/utils/file.py`

**作用**：文件工具。

生成 UUID 文件名，避免冲突。

### 10. `vectorizer/app/main.py`

**作用**：FastAPI 应用入口。

关键配置：
- 创建 FastAPI 实例
- CORS 允许 `localhost:3000` 和 `localhost:8080`
- 挂载路由到 `/api` 前缀
- 根路径返回服务信息

### 11. `vectorizer/.env.example`

**作用**：环境变量模板。

**作用**：Maven 项目配置。

关键依赖分组：

| 用途 | 依赖 |
|---|---|
| Web | spring-boot-starter-web |
| 安全 | spring-boot-starter-security |
| 参数校验 | spring-boot-starter-validation |
| 缓存 | spring-boot-starter-data-redis |
| 队列 | spring-boot-starter-amqp |

**作用**：主配置。

- 端口 8080
- 激活 dev profile

### 3. `backend/src/main/resources/application-dev.yml`

**作用**：开发环境配置。

- MySQL 连接（`characterEncoding=UTF-8`）
- Flyway 迁移路径
- Redis、RabbitMQ 连接
- `spring.codec.max-in-memory-size: 50MB`
- 自定义配置：`app.jwt.*`、`app.vectorizer.*`、`app.storage.*`

### 4. `SvgPlatformApplication.java`

**位置**：`backend/src/main/java/com/svgplatform/SvgPlatformApplication.java`

**作用**：主启动类。

`@SpringBootApplication` + `@MapperScan("com.svgplatform.modules.**.repository")`。

### 5. `common/response/ApiResponse.java`

**作用**：统一响应体。

字段：`code`（0 成功）、`message`、`data`。提供 `success()` 和 `error()` 静态方法。

### 6. `common/response/PageResponse.java`

**作用**：分页响应体。

字段：`items`、`total`、`page`、`size`。

### 7. `common/constant/ErrorCode.java`

**作用**：错误码常量。

定义了 OK / BAD_REQUEST / UNAUTHORIZED / FORBIDDEN / NOT_FOUND / CONFLICT / INTERNAL_ERROR。

### 8. `common/exception/BusinessException.java`

**作用**：业务异常。

包含 `code` 和 `message`，供 Service 层抛出。

### 9. `common/exception/GlobalExceptionHandler.java`

**作用**：全局异常处理。

拦截三类异常：
- `BusinessException` → 返回业务错误码
- `MethodArgumentNotValidException` → 返回参数校验错误

### 10. `modules/health/controller/HealthController.java`

**作用**：健康检查接口 `GET /api/health`。

### 11. `resources/db/migration/V1__init_schema.sql`

**作用**：数据库初始化脚本。

建 11 张表：users、files、conversions、posts、post_files、comments、likes、favorites、tags、post_tags、reports。

**作用**：认证接口。

### 16. `modules/user/controller/UserController.java`

## 七、转换模块

### 1. `infrastructure/storage/StorageProperties.java`

**作用**：存储配置。

从 `app.storage.*` 读取：
- type：local / r2 / oss
- local.baseDir：本地根目录
- local.publicPrefix：URL 前缀

### 2. `infrastructure/vectorizer/VectorizerProperties.java`

**作用**：矢量化服务配置。

从 `app.vectorizer.*` 读取：
- baseUrl：Python 服务地址
- timeoutMs：超时时间

### 3. `infrastructure/storage/StorageService.java`

**作用**：存储接口。

定义 store / read / delete / getPublicUrl / resolve 方法。

**设计意义**：后续换 R2、OSS 时只需实现新类，业务代码不动。

### 4. `infrastructure/storage/LocalStorageService.java`

**作用**：本地存储实现。

- store：按相对路径创建子目录并写入
- resolve：安全解析路径（防目录穿越）
- getPublicUrl：`publicPrefix + relativePath`

### 5. `infrastructure/vectorizer/VectorizerClient.java`

**作用**：调用 Python 矢量化服务。

用 `WebClient` 发 multipart 请求。

关键配置：
- `ExchangeStrategies.maxInMemorySize(50MB)` 解决大 SVG 被截断
- 超时从配置读
- 解析 JSON 响应

### 6. `modules/file/entity/FileEntity.java`

**作用**：文件实体，对应 `files` 表。

字段：id、userId、name、originalUrl、svgUrl、format、size、width、height、status、createdAt。

**命名说明**：类名用 `FileEntity` 而不是 `File`，避免与 `java.io.File` 冲突。

### 7. `modules/file/repository/FileMapper.java`

**作用**：文件数据访问。

### 8. `modules/file/dto/FileResponse.java`

**作用**：文件响应体。

### 9. `modules/file/converter/FileConverter.java`

**作用**：`FileEntity` → `FileResponse`。

### 10. `modules/conversion/entity/Conversion.java`

**作用**：转换记录实体，对应 `conversions` 表。

字段：id、userId、fileId、sourceFormat、targetFormat、status、paramsJson、resultUrl、errorMessage、createdAt、finishedAt。

### 11. `modules/conversion/repository/ConversionMapper.java`

**作用**：转换记录数据访问。

### 12. `modules/conversion/dto/ConvertResponse.java`

**作用**：转换结果响应。

字段：conversionId、fileId、status、svgUrl、originalUrl、width、height、message。

### 13. `modules/conversion/service/ConversionService.java`

**作用**：转换业务逻辑核心。

`convert` 方法流程：
1. 校验文件（非空、大小、格式）
2. 提取扩展名和路径（按 `yyyy/MM` 分目录）
3. 保存原图
4. 插入 files 记录
5. 插入 conversions 记录（status=processing）
6. 调 `VectorizerClient.vectorize`
7. 保存 SVG
8. 更新 files（svgUrl、width、height）
9. 更新 conversions（status=success）
10. 返回结果

失败时更新 conversions 为 failed 并记录错误消息。

### 14. `modules/conversion/controller/ConversionController.java`

**作用**：转换接口。

- `POST /api/conversions/convert`：上传并转换
- `GET /api/conversions/{id}`：查询记录

### 15. `modules/file/controller/FileController.java`

**作用**：文件接口。

- `GET /api/files/my`：我的文件列表（按创建时间倒序，限 100 条）

### 16. `config/WebMvcConfig.java`

**作用**：静态资源映射。

把 `/static/uploads/**` 映射到本地 `./data/uploads/` 目录。

## 九、整体数据流

```
用户浏览器
    ↓
Next.js 前端（3000）
    ├─ 用户操作触发 fetch
    └─ client.ts 自动带 JWT
        ↓
Spring Boot 后端（8080）
    ├─ JwtAuthenticationFilter 校验 token
    ├─ Controller 接收请求
    ├─ Service 处理业务
    ├─ MyBatis-Plus 读写 MySQL（3306）
    ├─ StorageService 保存文件到 ./data/uploads/
    └─ VectorizerClient 调用 Python
        ↓
Python 矢量化服务（8000）
    ├─ FastAPI 接收 multipart
    ├─ Pillow 预处理
    └─ VTracer 生成 SVG
        ↓ 返回 SVG
Spring Boot 保存 SVG，更新数据库，返回 URL
    ↓
前端展示 / 下载
```

## 十、启动顺序依赖

**首次启动**：

1. Docker 中间件（MySQL 必须就绪）
2. Python 矢量化服务（独立启动即可）
3. Spring Boot 后端（依赖 MySQL + Python）
4. Next.js 前端（依赖后端）

**日常启动**：

```bash
docker compose up -d
node scripts/start-dev.js
```
