# 接口文档

后端服务：`http://localhost:8080`

所有接口返回统一格式：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| 字段 | 说明 |
|---|---|
| code | 0 表示成功，非 0 表示失败 |
| message | 提示信息 |
| data | 业务数据，失败时为 null |

**鉴权方式**：需要在请求头携带 `Authorization: Bearer <token>`。

**错误码**

| code | 说明 |
|---|---|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录或登录已过期 |
| 403 | 没有权限 |
| 404 | 资源不存在 |
| 409 | 冲突（如邮箱已注册） |
| 500 | 服务器内部错误 |

## 四、转换

### POST /api/conversions/convert

**鉴权**：需要

**Content-Type**：`multipart/form-data`

**表单字段**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | File | 是 | 图片文件，PNG / JPG / WebP，最大 10MB |
| params | String | 否 | 矢量化参数 JSON 字符串，默认 `{}` |

**params 可选字段**

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| colormode | color / binary | color | 颜色模式 |
| hierarchical | stacked / cutout | stacked | 图层模式 |
| mode | spline / polygon / none | spline | 曲线拟合模式 |
| filter_speckle | int | 4 | 过滤小噪点 |
| color_precision | int | 6 | 颜色精度 |
| layer_difference | int | 16 | 图层颜色差异阈值 |
| corner_threshold | int | 60 | 角点阈值 |
| length_threshold | float | 4.0 | 曲线长度阈值 |
| max_iterations | int | 10 | 曲线拟合迭代次数 |
| splice_threshold | int | 45 | 拼接阈值 |
| path_precision | int | 3 | 路径坐标小数位 |

**成功响应**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "conversionId": 1,
    "fileId": 1,
    "status": "success",
    "svgUrl": "/static/uploads/2026/09/xxxx.svg",
    "originalUrl": "/static/uploads/2026/09/xxxx.png",
    "width": 400,
    "height": 300,
    "message": "转换成功"
  }
}
```

**失败情况（矢量化失败时）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "conversionId": 2,
    "fileId": 2,
    "status": "failed",
    "svgUrl": null,
    "originalUrl": "/static/uploads/2026/09/xxxx.png",
    "width": null,
    "height": null,
    "message": "矢量化服务不可用"
  }
}
```

**注意**：矢量化失败时，HTTP 状态码仍然是 200，`code` 仍然是 0，具体失败信息在 `data.status` 和 `data.message`。

**失败情况（参数错误）**

| 情况 | code | message |
|---|---|---|
| 文件为空 | 400 | 文件不能为空 |
| 超过 10MB | 400 | 文件超过 10MB |
| 格式不支持 | 400 | 仅支持 PNG / JPG / WebP |

## 八、Python 矢量化服务接口

### GET /api/health

**地址**：http://localhost:8000/api/health

**响应**

```json
{
  "status": "ok",
  "service": "Vectorizer Service",
  "version": "0.1.0"
}
```

### POST /api/vectorize

**地址**：http://localhost:8000/api/vectorize

**Content-Type**：`multipart/form-data`

**表单字段**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | File | 是 | 图片文件 |
| params | String | 否 | 矢量化参数 JSON，默认 `{}` |

**成功响应**

```json
{
  "success": true,
  "svg": "<svg ...>...</svg>",
  "width": 400,
  "height": 300,
  "elapsed_ms": 128,
  "message": null
}
```

**注意**：这个是内部服务，`code` 字段和 Java 后端不同，直接返回 `success` 布尔值。前端不直接调用，只由 Java 后端通过 WebClient 调用。

### POST /api/vectorize/download

与 `/api/vectorize` 相同，但响应头带 `Content-Disposition: attachment; filename="output.svg"`。

**Swagger UI**：http://localhost:8000/docs
